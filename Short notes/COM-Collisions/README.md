# Centre of mass & collisions — complete short notes (JEE + Olympiad)

Teacher-style condensed notes for **centre of mass, momentum, impulse and collisions**, built from the repository chapter `centre-of-mass-momentum/Centre-of-mass-momentum.md` (primary source, left byte-unchanged) with independent equation/sign/limit checking recorded in `SOURCE-AUDIT.md`. Coverage includes the Cengage *Mechanics II* chapter 1 floor (COM, impulse, collisions, deformation/reformation impulses, variable mass/rocket) plus a relevance-based olympiad layer.

- **Part I — JEE Main + Advanced**: 49 A4 sheets, numbered `JEE-01`…`JEE-49`
- **Part II — Olympiad / specialised extensions**: 26 A4 sheets, numbered `Olympiad-01`…`Olympiad-26`
- **75 sheets total**, 300 cards, 150 diagram panels; each sheet is 2480×3508 px @ 300 DPI (A4 portrait)
- Four cards per sheet; long items continue across cards rather than shrinking body type
